# TripMaker - Travel Agency Website

A modern, responsive travel agency website built with React, Vite, TypeScript, and Tailwind CSS.

## Features
- Responsive design with Tailwind CSS
- Sidebar with login/signup and social logins (Google, Facebook, LinkedIn)
- Pages: Home, Destinations, Packages, Booking, About, Contact, Terms
- State management with Zustand
- Lazy-loaded routes with React Router
- Type-safe with TypeScript

## Setup
1. Clone the repository
2. Install dependencies: `npm install`
3. Run the dev server: `npm run dev`
4. Build for production: `npm run build`

## Folder Structure
- `/src/components`: Reusable UI components
- `/src/features`: Feature-specific logic
- `/src/pages`: Route-based pages
- `/src/routes`: Routing configuration
- `/src/hooks`: Custom hooks
- `/src/store`: Zustand state management
- `/src/lib`: Utility functions
- `/src/config`: Site configuration
- `/src/styles`: Global styles
- `/src/types`: TypeScript interfaces
